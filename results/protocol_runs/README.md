# Protocol Run Results

This directory keeps the retained protocol result packages.

Primary result packages worth reading first:

1. `skillsbench_oracle_real_suite/`
   Real SkillsBench oracle execution path with valid suite artifacts.
2. `skillsbench_harbor_non_ceiling_repeat_bundle/`
   A retained SkillsBench non-ceiling example where protocol dynamics remain visible.
3. `tau_bench_retail_historical_suite/`
   Historical tau-bench import package with valid suite artifacts as supplementary support.

The most compact proof that SIP-Bench adds value beyond a single score remains `results/dryrun/summary.jsonl` at the repository root result surface.

Historical notes and planning drafts are intentionally excluded from this public result surface.
